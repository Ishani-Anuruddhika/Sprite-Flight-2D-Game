# Sprite-Flight-2D-Game

A 2D flight arcade game built with **Unity**. Navigate your sprite through obstacles, dodge hazards, and achieve the highest score possible!

---

## 🎮 Gameplay Overview
* **Objective:** Control your flying character/ship, avoid incoming obstacles, and survive as long as possible.
  * `W` / `A` / `S` / `D` or `Arrow Keys` — Move 

---

## 🛠️ Built With
* **Game Engine:** Unity 
* **Programming Language:** C#
